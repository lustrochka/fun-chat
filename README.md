## 💬 FUN-CHAT

A real-time chat application built with WebSockets. It allows users to authenticate, send and receive messages

## 🚀 Deployment

A [server-side](https://github.com/rolling-scopes-school/fun-chat-server/tree/main) application must be installed for deployment to work

## 🌟 Features

🔐 User Authentication: Login with validation, error messages, and automatic redirection for unauthorized users.

🖥️ Main Page: Displays authenticated user's name, logout button, and a list of users with online status.

💬 Message Features: Send, edit, delete messages, view delivery/read status, and scrollable message history.

📱 Responsive Design: Optimized for screen sizes from 1440px to 380px.

🔄 Real-Time Updates: Messages and user statuses update live via WebSocket. 

## 🔧 Installation and Setup

1. Clone server application

```sh
  git clone https://github.com/rolling-scopes-school/fun-chat-server.git
```

2. Install NPM packages

```sh
  npm install
```

3. Create the .env file and specify the port settings and server event log settings in it

```sh
  SERVER_PORT=4000
```

4. Start local server

```sh
  npm run start
```

5. Clone the repository
